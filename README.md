# Java Servlet Login Application

A web application developed using Java Servlets to demonstrate user login and authentication.

## Features

- User login using a web form
- Server-side request handling using Java Servlets
- Authentication and login validation
- Dynamic web application using Java web technologies

## Technologies Used

- Java
- Java Servlets
- HTML and CSS
- Apache Tomcat
- JDK
- Visual Studio Code

## Prerequisites

- JDK installed
- Apache Tomcat server
- Visual Studio Code or another Java IDE

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/anjuyadav21122006-crypto/Java-Servlet-Login-Application.git
   ```

2. Open the project in Visual Studio Code.
3. Configure Apache Tomcat in your development environment.
4. Deploy the application to Tomcat.
5. Start the server and open the application in your browser using the appropriate local URL.

## Learning Objectives

- Understand Java Servlets.
- Learn how HTML forms send requests to a server.
- Understand server-side request processing.
- Practice deploying a Java web application on Tomcat.
